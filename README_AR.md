# مربي الغنم - النسخة المطورة

هذه نسخة مصدر مطورة تضيف ملفاً فردياً لكل حيوان.

## الإضافات
- زر «فتح الملف» بجانب كل حيوان في قائمة القطيع.
- عرض الجنس والفئة والوزن وتاريخ الميلاد ورقم الأم والأب.
- تعديل الوزن والفئة وتاريخ الميلاد وبيانات الوالدين.
- سجل أحداث مستقل لكل حيوان: تلقيح، حمل، ولادة، علاج، لقاح، وزن أو أي ملاحظة.
- تستخدم الأحداث جدول `herd_events` الموجود مسبقاً، لذلك لم يتغير مخطط قاعدة البيانات ولم تُضف ترقية Room.

## البناء
ارفع محتويات هذا الأرشيف إلى المستودع، ثم شغّل GitHub Actions workflow المسمى Build Android APK. لا تعتبر النسخة جاهزة للتثبيت إلا بعد نجاح البناء وتنزيل artifact الجديد.

## ملاحظة مهمة
هذه نسخة مصدر أولية لهذه المرحلة. لم يُتحقق من بنائها محلياً لأن بيئة العمل لا تحتوي على Gradle؛ يجب أن يؤكد GitHub Actions نجاح البناء قبل التثبيت. احتفظ بالنسخة المثبتة وبياناتها إلى أن تختبر APK الجديد. لا تحذف بيانات التطبيق القديم قبل التأكد من سلامة النسخة الجديدة.
