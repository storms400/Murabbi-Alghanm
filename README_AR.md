# مربي الغنم – مشروع Android

هذا مشروع أولي قابل للبناء في Android Studio، وليس ملف APK جاهزاً.

## المتطلبات
- Android Studio حديث (يدعم Android Gradle Plugin 8.7.3)
- JDK 17
- اتصال إنترنت أول مرة لتنزيل اعتماديات Gradle

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `MurabbiAlghanmAndroid` في Android Studio.
3. انتظر مزامنة Gradle.
4. شغّل التطبيق على محاكي أو هاتف Android مع تفعيل USB debugging.

## ما تتضمنه هذه النسخة
- واجهة عربية RTL.
- قاعدة بيانات Room محلية SQLite.
- إضافة الحيوانات وتغيير فئتها وأرشفتها.
- إحصاء ديناميكي للقطيع النشط.
- تسجيل مشتريات الأعلاف مع دعم السعر المجهول.
- تسجيل أعمال الحظيرة والجز والرعاية.
- سجل حركات القطيع.

## تنبيهات
- هذه نسخة تأسيسية وليست نظاماً بيطرياً نهائياً.
- حصص التغذية في النموذج ليست توصيات علاجية أو عليقة معتمدة؛ يلزم ضبطها وفق الوزن وتحليل العلف وحالة الحيوان.
- لا توجد مزامنة سحابية أو إشعارات خلفية في هذه النسخة.
- لا يوجد APK مرفق؛ يمكن إنشاء APK من Android Studio عبر Build > Build APK(s).
